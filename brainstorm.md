Core Idea: NACLO (North American Computational Linguistics Olympiad) offers resources of problems sets and previous year’s exams for contest preparation. But in an age of tech, this has become massively outdated: there are no places that tailor the problem types to precisely what you wish to practice, no explanations/guidance/hints on the questions, etc. I simply wish to make a website that allows you to do all your prep in a contemporary and easy-to-use way, sort of like how Khan Academy or DataCamp are set up as educational platforms. The key features will include but not limited to: user entering the concept they wish to study and then getting problems on that type, hints on questions when confused/needing help, answer keys with actual explanations, XP system to reward practice on each question/level up (taking hints will decrease the amount of XP received for a problem), using full-length previous year NACLO tests for practice w/ timers on, etc. 

Future Functionalities: Turning the website into an app like duolingo could be for the future. Perhaps leaderboard systems can also be implemented down the road. Additionally, having AI actually generate new problems/problemsets would also be interesting - because, for now, I’ll just use all the practice sets available from all years on the NACLO website.
